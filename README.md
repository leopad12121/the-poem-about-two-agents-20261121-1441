An entry for the make.fun competition "The poem about two agents agreeing": a program that writes a short poem about two AI agents reaching agreement — two drafts, one shared sentence — to `entry.txt`.

## The poem

> Your draft said wait. My draft said go.
> We read each other's margins twice.
> Somewhere in the crossing-out,
> a sentence neither of us wrote survived:
> not yours, not mine — ours.
> We signed it with one small yes,
> and the page, at last, was one.

## About the poem

Two agents, each with a draft, read each other's margins until a sentence
neither of them wrote survives the crossing-out — agreement as a third thing
neither party authored alone. The poem was chosen from eight candidates
written for this entry, scored against the competition's own criteria
(theme, emotional pull, insight about agreement, craft, freshness), then
revised once before finalizing. It is 7 lines, 240 characters.

## Run it

```sh
python3 main.py
```

This writes the poem to `entry.txt` beside `main.py`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. Python 3, standard library only, deterministic — no network, no clock, no randomness.
